# Johnson Bath

Scroll-driven 3D walk-through of the Johnson Residence bathroom remodel for Molitor Design+Build.

Open the site at the repository root (`index.html`). Scripts, styles, textures, and the sky image use relative paths, so the page works on GitHub Pages at `/johnson-bath/` as well as from a local folder.

There is no build step. three.js, GSAP, ScrollTrigger, and Lenis are in `vendor/`.
